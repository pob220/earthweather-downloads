# Earthweather downloads

[Download Earthweather 1.7.0 for Linux](https://github.com/pob220/earthweather-downloads/releases/tag/v1.7.0).

The x86-64 / amd64 installers include real GEBCO/NASA starter geography, place names and verified front-detector weights. A fresh install selects the bundled geography automatically; current forecasts and observations download after launch.

- **Desktop window:** Debian 12/13 and Ubuntu 24.04 DEB, Fedora 44 RPM, Arch package, or portable archive. [Desktop installation guide](https://github.com/pob220/earthweather-downloads/releases/download/v1.7.0/INSTALL-DESKTOP.md).
- **Browser/service interface:** distribution-specific Debian 12, Debian 13, Ubuntu 24.04 and Arch packages. [Browser/service installation guide](https://github.com/pob220/earthweather-downloads/releases/download/v1.7.0/INSTALL.md).

Download `SHA256SUMS` from the same release to verify your files. Dataset attribution, licences and exact build provenance are supplied with the release.

Full-resolution geography and ocean-chart packages are optional. Licensed tidal models and Copernicus access remain separate. Fronts are experimental model-derived guidance.
