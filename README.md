# Earthweather downloads

[Download Earthweather 1.8.0 for desktop and Android](https://github.com/pob220/earthweather-downloads/releases/tag/v1.8.0).

- **Standalone Android tablet app:** install the ARM64 APK and launch **Earthweather** from the app drawer. Its engine, front detector, globe, bathymetry and coastlines are included. No PC or companion server is required. [Android installation and offline use](https://github.com/pob220/earthweather-downloads/releases/download/v1.8.0/INSTALL-ANDROID.md), [device validation](https://github.com/pob220/earthweather-downloads/releases/download/v1.8.0/ANDROID-VALIDATION.md).
- **Linux desktop window:** Debian 12/13 and Ubuntu 24.04 DEB, Fedora 44 RPM, Arch package, or portable archive, for x86-64 / amd64. [Desktop installation guide](https://github.com/pob220/earthweather-downloads/releases/download/v1.8.0/INSTALL-DESKTOP.md).
- **Linux browser/service interface:** distribution-specific Debian 12, Debian 13, Ubuntu 24.04 and Arch packages. [Browser/service installation guide](https://github.com/pob220/earthweather-downloads/releases/download/v1.8.0/INSTALL.md).

Installers include real GEBCO/NASA starter geography, place names and verified front-detector weights. Android additionally includes the ocean chart and prepared coastlines. Fresh forecasts and observations need internet access; saved products remain available offline. The optional NASA imagery upgrade downloads directly in the app and is retained locally.

Version 1.8 adds separate show-position and centre-position controls and a movable/minimisable appearance pane. Android supports tablet GNSS/network positioning and Wi-Fi NMEA with automatic tablet fallback. Weather readouts are available by tapping the globe.

Download `SHA256SUMS` from the same release to verify files. Dataset attribution, licences and build provenance accompany the release. Licensed XTD ocean models and account credentials are not distributed. Fronts are experimental model-derived guidance. Performance and hardware qualifications are recorded in the validation notes.
